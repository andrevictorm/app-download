## Como instalar no Android

1. Toque no link de download do app.
2. Quando o download terminar, abra o arquivo.
3. Se o celular pedir, permita "instalar apps desconhecidos" para o navegador ou para o app de arquivos.
4. O Android avisa que o app não é da Play Store. Para versão de teste, é normal: confirme a instalação.

Versões novas instalam por cima e mantêm a configuração.
